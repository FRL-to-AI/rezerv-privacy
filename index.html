Политика конфиденциальности

Приложение rezerv-rclone — личный инструмент владельца для резервного копирования собственных файлов в собственный Google Диск через rclone. Оно не публичное и не предназначено для других пользователей.

Какие данные используются

Приложение обращается только к Google Диску владельца аккаунта, который сам вошёл и выдал доступ. Никакие данные других людей не собираются.

Хранение и передача

Данные и токены доступа хранятся только на личных серверах владельца. Третьим лицам они не передаются, не продаются и не используются для рекламы или обучения моделей.

Отзыв доступа

Доступ можно отозвать в любой момент на странице myaccount.google.com/permissions.

Использование данных, полученных через API Google, соответствует политике Google API Services User Data Policy, включая требования Limited Use.
